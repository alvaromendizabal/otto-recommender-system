# OTTO | Public manual research source

Each `otto_feature_roundXX/` directory preserves the source and available saved notebook outputs from AWS. Canonical runtimes use the same folder names directly under the SageMaker home folder. Research dependencies, metadata hashes and immutable data remain necessary; source publication does not make a fresh checkout independently runnable without these artifacts.

Nothing here hides the implementation in a separate repository. Dataset artifacts are excluded to respect competition/data restrictions and repository size. Existing licenses and third-party notices are retained.
